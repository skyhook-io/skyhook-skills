name: external-pr-review
description: Review PRs from external contributors, understand their motivation, investigate deeply, and recommend a practical path to merge with minimal contributor back-and-forth. Use for external contribution reviews, not ordinary internal branch reviews.
---

Read `../skyhook-skills-commands/external-pr-review.md` relative to this
skill's installed directory and follow the complete workflow. In this repository,
the source is `../../../plugins/skyhook-skills/commands/external-pr-review.md`.

Review and recommend by default. Keep maintainer analysis separate from public
drafts. A review or triage request does not authorize posting or modifying a
contributor's work; follow the canonical command's approval boundaries and honor
any further action already authorized by the user.
