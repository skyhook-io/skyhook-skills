Read `../skyhook-skills-commands/external-issue-triage.md` relative to this
skill's installed directory and follow the complete workflow. In this repository,
the source is `../../../plugins/skyhook-skills/commands/external-issue-triage.md`.

Review and recommend by default. Keep maintainer analysis separate from public
drafts. A review or triage request does not authorize posting or modifying a
contributor's work; follow the canonical command's approval boundaries and honor
any further action already authorized by the user.
